# ArgoCD-RollingUpdate-RollBack-Deployment-Strategies

## 📌 Overview
This repository is created to practice **Kubernetes Deployment strategies** such as **Rolling Updates** and **Rollbacks**.  
It also shows how to use a **LoadBalancer Service** to expose applications and integrates **Argo CD** for GitOps automation.

## 🔹 What You’ll Learn
- Perform **Rolling Updates** in Kubernetes (upgrade app versions smoothly).  
- Perform **Rollbacks** (revert to a stable version if issues occur).  
- Expose applications using a **LoadBalancer Service**.  
- Integrate **Argo CD** to automate deployments from Git.
